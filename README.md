# 铝型材 CBAM 碳核算平台

公开地址：https://wangmeng-daw.github.io/cbam-platform/

完整核算页面直接托管在 GitHub Pages，不跳转其他平台，不需要登录或管理员。核算引擎、参数、PDF 和 Excel 报告生成均在浏览器运行。所有代码、字体样式和脚本均随网站发布，无需第三方 CDN。

## 数据保存

勾选保存后，草稿和核算记录保存在当前浏览器的本地存储。清除网站数据或更换浏览器、设备后不会保留或自动同步。原在线版本的记录不会自动转入。记录存储失败会明确报错，不影响不保存的即时核算与导出。报告使用记录保存时的参数快照。

## 构建与发布

需要 Node.js 22.13+，执行 npm ci、npm run build。GitHub Pages 使用 main 分支的 /docs 目录，提交构建后的 docs 后自动发布。npm run dev 启动本地静态开发服务器。

入口 browser/main.tsx；交互 app/platform.tsx；本地存储 browser/storage.mjs；报告 browser/report.ts 与 browser/files.mjs；核算引擎 lib/engine.mjs。

测试：npm test；node scripts/verify-browser-storage.mjs；node scripts/verify-browser-reports.mjs。

旧服务端源码保留用于历史参考，不会打包到公开页面，网站不会请求旧服务端。

## 2026 年 11 月界面与公式更新

左侧导航包含企业管理、产品碳足迹计算、第三方因子接入、碳价行情和系统管理。产品信息位于企业管理下；生命周期模型与产品碳足迹报告位于核算模块下。企业、产品、模型和第三方燃料因子可在本地维护，系统管理支持 JSON 资料备份和恢复。第三方因子为本地录入接入，不会连接参考系统或上传资料。

默认值模式仅使用整品默认值，不填写前体。整品默认值按三位小数参与计算；免费分配 = 所选生产路线基准 × 年度 CBAM 因子；证书数 = ceil(max(0, (整品默认值 − 免费分配) × 输欧量))；成本 = 整数证书数 × 碳价。计算保留精度，界面与报告中的总排放显示整数，单位排放显示三位小数。普通因子列表显示两位小数，并提供完整精度供核对。

可在首页载入文档案例：CN 76041010、中国、原铝、2026 Q2、1,000 吨、情景碳价 73.43 欧元。结果为 5,369 tCO₂e、3,922 张证书、287,992.46 欧元。案例碳价是情景输入，不会覆盖内置季度价格。

额外回归检查：node scripts/verify-browser-integration.mjs；node scripts/verify-workspace.mjs。

## 2026 年 11 月 11 日实际值文档口径

新建实际值核算默认使用用户提供的《实际值计算示例（平台开发用）》口径。支持多个7601/7604/7608产品、独立工序燃料、阳极炭净耗与损失率、PFC频率/持续时间、上游产品关联和分摊。按产品总产量校验输欧量与下游投入量，拒绝循环引用。历史核算快照保持原口径。

燃料排放先保留1位小数；CF4与C2F6先保留2位小数后计算PFC当量并取整；工序直接排放取整；上游排放按实际消耗/上游产量分摊；SEE保留3位后参与成本计算。按文档仅扣本工序基准乘年度CBAM因子；成本使用未取整排放负担，整张证书参考数另外显示。此项目文档口径与欧盟正式清缴口径存在差异，界面和导出文件均标识为文档口径。

内置实际值示例按最终60%分摊公式使用120000吨前体，不计文字输入举例中的煤，采用75.36欧元情景价（不覆盖内置季度价）。复算结果：未锻轧铝SEE 1.603，成本1299658.56欧元（129.97万）；铝型材SEE 1.749，成本14395757.04欧元（1439.58万）。默认值案例仍为3922张、287992.46欧元。

回归检查：node scripts/verify-document-example.mjs。核心实现：lib/document-engine.mjs；交互：app/document-assessment.tsx。

### 独立换数验证与精度修正

实际值版本2.0.1采用精确十进制/分数运算，按文档规定的步骤四舍五入；上游分摊在工序之间传递完整精度。修正二进制浮点临界值偏差，例如C₂F₆的0.605应保留为0.61、成本37.675欧元应保留为37.68欧元、380.835万欧元应保留为380.84万欧元。未取整负担直接用于成本和证书参考数，不提前截为8位小数。燃料因子的GJ→TJ换算也使用精确运算；页面保留输欧量的小数。

`node scripts/verify-document-variants.mjs`：270组独立输入（20组定向场景与250组固定种子随机工况），13,749项引擎结果核对，以及中英文PDF/Excel的48项核对。覆盖多燃料、损失率、收集效率、上游分流、双来源混合、三级链、年度因子、小数数量、零输欧量、低于免费分配、缺失价格及四舍五入上下边界；另验证产品顺序不影响结果、修改出口量和碳价不影响生产排放、输入不被修改。

预期值由独立的Python标准库Fraction程序生成，不导入平台计算函数或配置：`python scripts/document-reference.py > scripts/fixtures/document-validation.json`。所有数据为合成测试数据，随机种子20261111。原文档双工序案例及默认值案例结果保持不变。历史快照保留历史结果；需按修正版更新时加载输入后重新计算。

## 当前版本：2026 年 11 月 13 日产品库与精度规则

本节替代上文11月11日版本的取整规则。使用《默认值（铝产品）V3.xlsx》和《基准值（铝产品V5）.xlsx》。按用户确认保留59条产品记录，对应58个唯一CN；76101000的两条源记录共用计算数据。CN选择、产品档案、实际值与默认值计算均覆盖全产品库。

中国默认值直接取G/H/I年度含加价列，2026取G、2027取H、2028–2030取I，不重复加价。其他国家没有匹配行时显示缺失，不套用中国数据。实际值取A列原铝/再生铝基准，默认值取B列对应路线；A列合并单元格对两种路线共用。原始直接排放列中的4148/4881等值只作溯源，不替代年度含加价列。

引擎3.0.0按十进制四舍五入：燃料、阳极、CF4/C2F6、PFC当量、工序排放、前体分摊、单位排放和输欧排放保留5位；排放因子和基准值保留3位；排放负担保留5位后，证书数量向上取整。金额保留2位。沿用文档的成本公式：默认值成本用整数证书数，实际值成本用未取整为整张证书的排放负担。页面与PDF/Excel同步，旧保存结果不被改写。

原双工序数据按新精度复算：未锻轧铝SEE 1.60286、成本1298814.53欧元；铝型材SEE 1.74891、成本14394990.63欧元。这属于明确的新规则结果，不再要求等于旧示例的三位小数结果。原默认值案例仍为3922张、287992.46欧元。

数据溯源见`lib/aluminium-library.json`，包括源工作表、行号、文件哈希和重复记录说明。导入脚本`python scripts/import-aluminium-library.py <workbook-directory>`；独立原文件核对`python scripts/verify-aluminium-sources.py <workbook-directory>`，核对1450个数据项并生成580组Decimal预期结果。`node scripts/verify-aluminium-library.mjs`核对全58个CN、5年、两路线的默认值结果和实际A列基准（各580组），并检查导出数字格式。`node scripts/verify-document-variants.mjs`现包含273组五位小数工况、13823项计算结果和48项报告核对。
